# Getting NIGHT Tokens: Exchanges, Bridging & Wallet Funding on Mainnet

**Midnight Network** is a data-protection blockchain built on the Cardano ecosystem. Its native token, **NIGHT**, powers transaction fees, proof generation, staking, and governance. This tutorial covers everything you need to know about acquiring, storing, and using NIGHT tokens on mainnet as of May 2026.

---

## 1. What Is NIGHT?

NIGHT is the utility and gas token of the Midnight Network. You need it to:

- Pay for transaction fees on Midnight's sidechain
- Submit zero-knowledge proofs to the proof server
- Deploy and interact with Compact smart contracts
- Stake as a network operator
- Participate in on-chain governance

As of May 2026, NIGHT has a circulating supply of approximately 200 million tokens with a market cap of roughly $6.5 million USD.

## 2. Exchanges That List NIGHT

### Centralized Exchanges (CEX)

**Binance** is currently the primary centralized exchange listing NIGHT/USDT. You can:

1. Log into your Binance account
2. Navigate to Markets → search "NIGHT"
3. Trade NIGHT/USDT spot pair
4. Withdraw NIGHT to your personal wallet

Binance supports NIGHT withdrawals to native Midnight addresses. Minimum withdrawal is typically 100 NIGHT (~$3.28 USD as of writing).

**Other CEX listings:** As adoption grows, additional exchanges may list NIGHT. Check CoinGecko or CoinMarketCap for the most current exchange list.

### Decentralized Exchanges (DEX)

NIGHT can be acquired through:

- **Minswap DEX** (Cardano ecosystem) — Swap ADA for NIGHT
- **SundaeSwap** — Another Cardano-native DEX supporting NIGHT pools
- **WingRiders** — Additional liquidity pools for NIGHT/ADA

### Peer-to-Peer Options

- Discord community (`#marketplace` channel in Midnight's Discord server) — Some community members sell NIGHT directly
- Telegram groups — Exercise caution and use escrow for P2P trades

## 3. Wallet Setup for NIGHT

### Midnight Browser Wallet (Recommended)

The official Midnight Wallet browser extension supports:
- Chrome/Brave/Edge
- NIGHT balance display
- Transaction signing for dApps
- Proof server interaction

**Setup:**
1. Install the Midnight Wallet extension from the Chrome Web Store
2. Create a new wallet (save your 12-24 word seed phrase offline!)
3. Fund with NIGHT tokens via exchange withdrawal

### Vespr Wallet (Mobile)

A mobile-first Cardano + Midnight wallet supporting:
- ADA and NIGHT on the same interface
- QR code scanning for transactions
- dApp browser for web3 interactions

### Yoroi Wallet (Desktop/Mobile)

Yoroi has added Midnight Network support:
- Light wallet (no full chain download)
- Hardware wallet support (Ledger)
- Built-in DEX aggregator

### Hardware Wallets

- **Ledger** — Supports NIGHT via the Cardano app + Midnight companion app
- **Trezor** — Roadmap support coming in late 2026

## 4. How to Buy NIGHT (Step-by-Step)

### Method A: Via Binance (Fastest)

1. **Deposit funds** — Send USDT or fiat to your Binance account
2. **Buy NIGHT** — Go to NIGHT/USDT spot market, place a market or limit order
3. **Withdraw** — Go to Wallet → Withdraw → NIGHT, enter your Midnight wallet address

**Withdrawal fees:** Usually 0.1-1 NIGHT depending on network congestion
**Confirmation time:** 5-15 minutes for the transaction to finalize

### Method B: Via Cardano DEX (More Private)

1. **Buy ADA** on any exchange (Coinbase, Kraken, Bybit)
2. **Withdraw ADA** to a Cardano wallet (Vespr, Daedalus, Yoroi)
3. **Connect to Minswap** or SundaeSwap via web interface
4. **Swap ADA for NIGHT** using the NIGHT/ADA pool
5. **Bridge NIGHT** from Cardano L1 to Midnight sidechain (see Section 5)

### Method C: Community Purchase

1. Join Midnight Network's Discord
2. Visit the #marketplace channel
3. Find verified sellers with positive feedback
4. Complete transaction using a trusted escrow

## 5. Cardano-to-Midnight Bridging

### Current State (May 2026)

The **official Midnight Bridge** is live and allows transferring NIGHT between:
- Cardano L1 (where NIGHT exists as a native asset)
- Midnight sidechain (where NIGHT is used for gas and dApp interaction)

**Bridge Steps:**
1. Open the Midnight Bridge dApp at `bridge.midnight.network`
2. Connect your Midnight Wallet
3. Select "Cardano L1 → Midnight" direction
4. Enter the amount of NIGHT to bridge
5. Confirm (bridge fee: ~1-2 NIGHT)
6. Wait 10-30 minutes for transaction finality

**Bridge Back (Midnight → Cardano L1):**
1. Connect your wallet to the Bridge
2. Select "Midnight → Cardano L1"
3. Enter amount and confirm
4. Wait for rollup finalization (~1-2 hours during high traffic)

### What's Coming

The Midnight team has announced several bridge improvements:
- **Faster finality** — Reducing bridge time to under 5 minutes (Q3 2026)
- **Multi-chain bridges** — Ethereum and BSC integration in development
- **Trustless relayers** — Removing any centralization in the bridge (Q4 2026)
